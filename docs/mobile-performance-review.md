# 蓝皮书图片加载与移动端优化草稿

基线：`e8430f7353dd08e9d4150d4b0d34cf352906714b`（2026-09-07）。
本草稿针对用户反馈的图片加载慢和手机阅读体验，等待电脑预览及手机真机确认后再合并。

## 已确认的原因

- 61 张截图全部以 base64 写入章节 HTML，截图与正文必须一起下载。给内嵌图片加 lazy 属性也不能减少 HTML 的传输量。
- 智能定价章节约 2.41 MB，其中大部分是截图；没有加载状态时，用户容易把空白正文误认为没有打开。
- 首页原本还需要先下载约 220 KB 的全文搜索元数据，即使用户不搜索。
- 图片没有明确尺寸，解码后会改变排版；手机端截图缩小后文字不易看清，且没有大图查看入口。
- 原有手机布局沿用了桌面导航和表格；目录、长标题、复制话术和截图查看缺少专门适配。
- GitHub Pages 的跨地区访问速度可能叠加影响。这里尚未完成国内网络实测，不能用文件缩小比例推算实际秒数。

## 草稿中的修改

1. 截图拆为独立 WebP：长边 720 / 1280 / 原始 1800 px（窄幅手机截图保持原尺寸）。浏览器根据屏幕宽度和像素密度选择文件。
2. 每篇第一张截图优先加载，其余图片延迟加载。添加宽高以预留位置；原尺寸大图保留，点开后可放大并横滑查看细节。
3. 全文搜索索引单独按需加载，不阻塞首页；搜索支持失败重试。
4. 章节加载显示状态、处理 HTTP 错误和 20 秒超时；失败不缓存，允许重试。同一篇并发请求复用；过时的章节结果不能覆盖当前页面。
5. 手机顶部按钮、封面、分类入口、目录、正文边距和长标题调整；宽表格局部横滑，两列表格保持正常排版；提示词自动换行。
6. 手机增加本篇小节目录、顶部分享入口、截图大图和微信号复制。搜索提供明确的关闭按钮；目录面板限制在视口范围内，按钮增加触摸面积。
7. 小蓝面板展开时收起 FAB；修复章节锚点及键盘跳到正文；分类卡定位对应目录分组。

## 已完成验证

- 8 项 Node 回归测试：请求乱序、退出文章后的旧请求、404 重试、同篇请求复用、搜索延迟加载、损坏的本地存储、FAB／键盘跳转、完整目录及旧缓存兼容。
- 资源检查：61 张截图、所有 srcset 文件存在且可解码；图片尺寸与声明一致，章节第一图 eager、后续图 lazy；37 篇均有搜索正文。
- JS 语法与 Git diff 空白检查通过；已抽查压缩后截图的可读性。

尚未完成改版的浏览器渲染及手机真机测试：当前预览环境不能访问本地服务，浏览器安装下载也未成功。因此不能据此声称已经解决所有手机布局问题，或承诺具体加载秒数。

## 电脑预览

下载本 PR 分支后，在仓库根目录执行：

```bash
python3 -m http.server 8080
```

打开 `http://localhost:8080/`。需要 HTTP 服务，不能直接双击 HTML 文件，因为章节和搜索索引通过 fetch 加载。

测试命令：

```bash
node --test tests/reader.test.cjs
python3 tests/assets.test.py
```

Python 资源测试需要 Pillow。截图转换脚本为 `scripts/optimize-images.py`，只处理新加入的内嵌截图，已拆出的资源不会重复转换。

## 合并前人工验收

- 手机宽度 320 / 375 / 390 / 430 px：封面、目录、文章不产生整页横向滚动；长标题和顶部按钮不重叠。
- iPhone Safari 和 Android Chrome：截图点开、放大、左右滑动、关闭后能回到原阅读位置；二维码长按及微信号复制可用。
- 阅读第 17、25 章和附录 D：表格可局部横滑，本篇小节链接定位正确，提示词能复制。
- 搜索框在键盘打开时仍可输入、关闭、点击结果；小蓝面板关闭按钮始终可见。
- 慢网连续点击不同章节、返回封面，再断网重试：正文标题与内容一致，不闪回旧文章。
- 开发者工具 Network：首页不请求 search-index，正文不再含 data:image；滚动前不主动下载整章所有大图。
- 使用实际用户常用的国内移动网络测首次打开与再次打开。如果仍慢，再评估其他静态托管/CDN，另行确认迁移方案。

权限／自动调价／评价审批口径、v1.0 与 v4.2、章节号与书内引用、直播价格与 ROI 的来源和统计周期仍需独立内容复核。本草稿未擅自更改这些业务结论，也未发布或合并到 main。

## 缓存兼容

新版入口使用 `assets/reader.js`、`assets/reader.css` 和 `data/manifest-lite.json`。保留原 `app.js`、`app.css`、`manifest.json`，让仍缓存旧首页的访客继续使用完整搜索数据，避免脚本与数据格式跨版本混用。
