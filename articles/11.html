场景痛点

口头交班最容易漏事：上一班处理了什么、哪间房客人有特殊要求、哪个工单没结、哪笔押金没退，全靠嘴说和翻聊天记录，既慢、又常出现"我不知道上一班说了啥"。

把这套结构化交班交给 AI 汇总：

  • 它把散落在 PMS、交接表和群里的信息，自动收成一页纸；
  • 帮你省下大量整理和复述的时间。

（具体能省多少，以你门店的实际交接情况为准，建议自己跑一周、前后对比一下最实在。）

用工作台哪个能力

  • 第一阶：Agent 经 PMS CLI 读当班入离、房态变动、客人备注，结合你放在工作区的交接表、保洁待办，以及工作群里"说了但没落表"的事项；
  • 第三阶（进阶）：自动化设 22:00 出晚班交班摘要、08:30 出早班待办，到点自动汇总、只做提醒，不替人最终确认。

操作步骤

  1. 先固定信息源：PMS 的入离/房态/备注 + 交接表 + 保洁待办 + 群内未落表事项，这四类是交班摘要的稳定来源。
  2. 交班前让 Agent 读取当班全部变动和未结事项。
  3. 它按"今晚必须知道 / 明早必须跟进 / 例外事项"三块生成一页摘要。
  4. 交班双方对着摘要过一遍，只补充 Agent 不知道的口头信息，确认后让它记进系统。
  5. 每月让它把最近交班摘要里反复出现的问题，按"说明问题 / 流程问题 / 现场问题"三类整理成对策表（这也是新店首月最值得做的一次复盘）。

世鑫酒店成品样例

一页纸，四块清清楚楚：

  • 在住 11 间：观山 302 客人要婴儿床、21:00 已送；归隐客人延退到 13:00 已批；
  • 待办 3 条：明早 8 点前修听雨 205 花洒、携程 3 条待回咨询、抖音团购券 2 张待核；
  • 异常 1 条：观山 305 押金 500 元预授权未释放，明早跟进；
  • 下一班注意：夜间私域知识库已搭好，常见问题（房态/价格/政策/周边）AI 秒回，复杂问题（包栋/团建/投诉）触发转人工。

常见坑

  • 只罗列不分类：一堆流水账，下一班抓不到重点。→ 强制"今晚必知/明早必跟"分类。
  • 没有"下一班必须注意"：最关键的风险被埋在最后。→ 单独成块。
  • 口头信息不回写：→ 交班时人工补充并让 Agent 记进系统，别留在嘴里。
  • 指望自动化替人拍板：→ 自动化只汇总和提醒，最终确认永远是人。
