① 最基础的 4 个词，先认识

  • 云 PMS：订单来了的酒店管理系统，管订单、房态、价格、渠道、账务，是 Agent 的数据来源。
  • AI 工作台：统一操作入口，本质就是一个对话框，你在这儿给 Agent 派活。
  • 酒店经营 Agent：工作台的执行核心，能听懂目标、拆步骤、调工具、交结果的"数字员工"。
  • 通用 AI：豆包、通义千问、DeepSeek、ChatGPT 这类什么都能聊的聊天框。
    • 它像"百宝箱"，懂百科，但没连你的 PMS、不懂你这家店；
    • 写文案、脑暴找它；真正的经营操作，要在订单来了工作台里做。

② Agent 干活的三只"手"

  • PMS CLI：操作自家 PMS 的手，管订单、房态、库存、房价、财务、客史；查询只读、改动先给你预览。
  • 渠道 CLI：操作携程 / 美团 / 飞猪 / 抖音后台的手。
    • 在技能社区"市场"里装对应技能（如携程 CLI 运营助手）；
    • 配合 AI 浏览器的登录态使用，不用自己写接口。
  • AI 浏览器：把各 OTA 后台内嵌进客户端，登录后 Agent 就能进已授权后台操作；几个门店账号常驻登录，就能诊断几个店。

③ 怎么派活、怎么把活存下来复用

  • Prompt（指令）：这一次怎么交代任务，说清"对象 + 时间 + 范围 + 产出"就行。
  • Skill（技能）：把一类事的目标、资料、步骤、边界、工具打包，以后一键复用；分自带功能、社区技能、个人技能三类。
  • 技能·连接器 / 技能社区：左侧「技能·连接器」是统一入口。
    • 「技能社区」是扩展货架：按酒店业务、内容创作等分类浏览，点卡片【+】安装；
    • 「已安装」按系统 / 市场 / 个人 / 第三方四种来源管理，建议开"自动更新技能"；
    • 「连接器」用来接通企业微信 / 钉钉 / 飞书；
    • 右上「+ 添加技能」可上传现成技能，或创建新技能（进入内置 $skill-creator）。

  • PMS 自带的 7 大 AI 功能：PMS 顶部彩色「Ai」标签里，开箱就有、不用安装：

    • AI 智能定价、AI 评价助手、OTA 自动对账、AI 小红书笔记、AI 直播、AI 私域运营；
    • 以及经营报表——现在更推荐直接在工作台对话框说要看什么、自动取数出表，比固定报表灵活；
    • 设规则、看看板进「Ai」标签；一句话调用就在对话框说，两边数据同源。技能社区里的扩展技能不属于这 7 个。 ④ 智能定价词包（16 篇细讲）

  • 用前先设对三件事：

    • ① 我的商圈 / 核心竞对：重新拉一遍周边酒店，把最直接的竞品"设为核心竞对"——它直接影响定价，选错全盘偏；
    • ② 标准价：分周一到周日的基准价，不准就手动逐天改，它是一切调价的底子；
    • ③ 最低价 / 最高价：底价红线和节假日上限，要设得符合常识。
  • 人机磨合期：定价是综合多源数据的"黑盒"，头 1～2 个月自动要开（不然 AI 学不到），人要更认真盯、及时纠偏，配合越久越准。这也是人和 AI 互相学习的过程——别用旧思维框住 AI，让 AI 帮你看到你看不到的机会。日常把红线、报表和策略设好，例外时现场的人握"价格介入"权限拍板。
  • 几个真机控件：
    • 「价格限制 · 批量设置」：多选房型、选区间、勾周几、逐房型填最低 / 最高价；
    • 「定价策略」：定调价节奏与渠道规则；
    • 「手动智能定价」：当场出建议、人逐条拍板（新手用）；「自动调价」：在区间内自动调（熟了再开）；
    • 「定价分析」：点日历格看这一价由哪几项加减而来、大白话原因和市场排名；
    • 「价格介入」：人工覆盖某天某房的价。
  • 硬兜底：建议价一旦低于最低价，"最终定价"会自动抬回最低价，AI 破不了底价；改完点「同步价格至 PMS」才落地。
  • AI 定价周报：按周汇总调价次数、涨跌次数、最终入住率与 RevPAR。
  • 竞对调研技能：技能社区里「携程外网数据抓取」技能 + 自动化，可定时抓各店各房型售卖价、汇总成 Excel，人再判断加减。

⑤ 日常运营这几个功能

  • 智能评价：分评价管理 / 分析 / 设置三个子页。
    • 「疑似差评」标签自动归集"打高分、文字却在抱怨"的隐性差评，不用你逐条翻，点进去处理、转内部整改；
    • AI 只起草回复，你确认后才发到平台；
    • 顶部给全渠道点评数、差评数、好评转化率、待回复数和八维评分雷达。
  • 自动化对账：按账期自动跑（预付周结、现结月结），每条列账期、笔数、金额、"一致无差异"还是具体差异、预计到账金额与日期，还集成待开票总额；无差异自动通过、只报差异项。
  • AI 直播间：PMS「Ai」→AI 直播里新增，先平台授权、配云台和紧急联系人；按直播时长计费，携程直播不消耗时长。

  • 小红书笔记 · 碰一碰：先维护门店"植入信息"，选四种风格之一（约 200 算力 / 篇）生成图文，再下载二维码或写 NFC 标签，客人自愿扫码自取、用自己账号发布；你不代发、不指定好评。 ⑥ 私域接待与自动化

  • 客人对话 / 知识库（AI 私域运营）：这个功能不在 AI 工作台里配置，是在 PMS「Ai」→「AI 私域运营」模块里单独部署。AI 通过你的企业微信（个人微信也能接入，有企业微信会更顺手）先替你接客，开总开关前按三步走：

    • 第一步：在「知识库」配好 FAQ、话术、房源与周边信息，它照此回答、不瞎编；
    • 第二步：在「客人对话」接入企业微信，提前设好"触发人工"条件（问包栋团建、要优惠、来投诉、反复追问就自动转人）；
    • 第三步：最后才打开底部「AI 回复」总开关，任何会话都能一键「转人工」。
    • 注意边界：私域咨询可 AI 先回、碰条件转人；OTA 平台评价必须你确认后才回。
  • Automation（自动化）：本质是"到点自动发起一段你预设好的对话"，像给数字员工排值班闹钟，填三块：
    • ① 标题与描述：这项活干什么；
    • ② 定时策略：每天 / 每周、几点跑；
    • ③ 消息发送：结果发到哪个会话 / 工作区（选了某门店工作区，就带着这家店的资料跑）。
    • 不会写可点「使用模板」带出官方四张模板（携程巡店、美团巡店、昨日营业、当月营收）再改，如定时晨报、22:00 交班摘要。
  • $skill-creator（技能创建器）：工作台内置的对话式造技能入口，它依次问四件事——技能目标、触发场景、2~3 条典型请求、是否需要脚本 / 资料 / 模板，答完自动做成技能，不用写代码。

⑦ 账号、安全与手机端

  • 工作区 / 会话记录：工作区放你上传的资料和产出文件；会话记录留存每次任务全过程，可回溯。
  • 访问权限（三档）：输入框旁盾牌图标的安全阀。
    • 请求审批：访问外部网页或文件前都问你；
    • 自动审批：低风险自动、敏感操作仍确认；
    • 完全访问：可联网和读本机文件，但敏感操作在任何档位都要你确认。新手从前两档起步。
  • 手机端（订单来了 App）：扫码绑定电脑、一台电脑绑一个手机、换手机先解绑再重绑。
    • App 顶部显示所连电脑名和在线绿点——手机是遥控器，真正干活的是那台在线电脑，电脑关机 / 休眠就跑不了；
    • 手机可远程派活、拍照传图、看进度、点确认、收文件再转发；装技能、配自动化、登录渠道这类一次性管理操作仍以电脑为准。
  • 密码记事本（市场技能）：本地保存并自动填写各渠道账号密码，配合 AI 浏览器免去反复登录。
  • 携程金字塔 / 旅拍发布助手（市场技能）：前者巡检金字塔投放、出诊断与建议；后者用 PMS 图片生成旅拍图文，你确认后才发布。
  • 变更预览：改价、改库存、退款等写操作执行前，先列出"准备改成什么样"，你确认才提交。
  • 算力值：运行 AI 能力消耗的额度，注册有赠送、一池多模块通用，在账号助手查看。

⑧ 经营指标与总原则

  • 第一阶 / 第二阶 / 第三阶：本书能力主线——说任务、装技能、自动化 / 造技能（进阶）。
  • OPC（One-Person Company）：一个人 + AI + 外部专业服务商，构成一人经营中台。
  • ADR / RevPAR / OCC：平均房价＝客房营收÷已售房晚；每可售房收入＝客房营收÷可售房晚；出租率＝已售房晚÷可售房晚。
  • 在手率：未来某一天目前已订出去的比例，定价决策的核心依据。
  • 六条红线：破价 / 关房大库存、投流预算、赔偿退款承诺、严重投诉回复、合同品牌公开信息——永远人工审批。
