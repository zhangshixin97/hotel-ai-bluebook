第一次接触 AI 不用发怵。全书翻来覆去的新词就下面十几个，先混个脸熟，后面读到随时翻回来对照——它们只是名字，不难。

书里的词 用大白话讲 打个酒店人熟悉的比方
通用 AI 豆包、通义千问、DeepSeek 这类什么都能聊的聊天框，懂百科但不懂你家店 一个博学的路人，见多识广，但不知道你店里今天住了几间
经营 Agent（AI） 一个住在系统里、24 小时不休息的数字员工，你派活、它去干、干完把结果交给你 一个记性极好、手脚极快，但大事一定找你签字的值班经理
提示词 / Prompt 你给它派活时说的那句话 你口头给店长交代任务
技能 / Skill 把"一类活该怎么干"写成的一份固定操作手册，装上后一键就能干 一张岗位 SOP 作业卡，谁照着做结果都一样稳
第一阶 / 第二阶 / 第三阶 三种由浅到深的用法：第一阶动嘴交代一次、第二阶备好手册反复用、第三阶让它到点自己干 ①临时口头派活 ②把好方法写成 SOP ③定好闹钟让它按时值班
CLI 它在后台替你点鼠标、查数据、改东西的那只"看不见的手"，你不用懂技术 一个熟门熟路、会自己进 PMS 和各平台后台办事的老员工
AI 浏览器 它替你登录、查看携程美团等平台后台的窗口 一块同时挂着所有平台后台、不用反复切号的大屏
连接器 接通企业微信 / 钉钉 / 飞书，让它能把晨报、预警发到你工作群 给数字员工配的一部"群对讲机"
工作区 按门店建的文件夹，放你上传的资料和它产出的结果 每家店一个档案袋，底料和产出分开放
算力值 用 AI 功能时消耗的"电量"，注册有赠送、全模块一池通用 手机话费流量，用多少扣多少
变更预览 它改价改房之前，先列一张"我准备这么改"的单子给你看，你点头才真改 员工动手前先拿草稿找你签字
访问权限三档 你给它多大自主权：每步都问你 / 低风险自动、敏感才问你 / 全放开（但敏感操作仍会问你） 给新员工授权，从"事事请示"逐步到"放心交办"
自动化 到点就自己跑的定时任务 给数字员工排的值班闹钟
挂载 / 调用技能 这一次干活用上某个技能 这次让它照着某张 SOP 办
沉淀 / 固化 把一次跑顺的做法存下来、以后直接复用 把好经验写进 SOP，别只留在嘴上和脑子里
OCC / ADR / RevPAR 三个最常用经营指标：出租率 / 平均房价 / 每间可售房收入（正文首次出现都会再解释） 酒店人的"心率、血压、体温"

记住一句话就够了：看到英文和缩写别紧张，你要做的从来不是学技术，而是像给店长派活一样，把"哪家店、什么时候、看哪些、要什么结果"说清楚，剩下的它去干。
